# Menu-App
This is a project that simulates an online ordering app, using a given menu. This entire project was done using Java, with imports such as ItemListener and Graphics. 

# Features 
- No limit on number of items ordered
- Visual of each item during selection
- Background for ambience
- Calculate button to find total when user is finished selecting
- Reset cart if user decides to restart order

# Process 
I started by deciding what items I would include on the menu for the app. I then found images online and used them to represent each of the menu items.

I then created the class for the main panel that everything would be placed on, which was the background and total size of the window 

After, I created the main class that created objects with each of the images, as well as adding them to panels and ItemListener. Each of the images were placed at specific length and width to avoid overlap.

Finally, I added the functions of each of the buttons. When any of the items were clicked on by the user, it would be added to the cart (visible to user) and the total price is increased each time. They can continue to add as many items as they want. When the "Reset" button is clicked, the cart is emptied and the order is reset. When the "Calculate" button is pressed, the items are ordered and the total price is displayed on the screen to the user.
